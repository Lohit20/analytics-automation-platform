# Business Reporting Dashboards with API Data Integration

A Python-based reporting pipeline that extracts live FX (foreign exchange) rate data
from a public API, transforms it into KPIs, volatility, and a currency risk / hedging
cost-benefit model, and produces both a Power-BI-ready data feed and a formatted Excel
report — automated end to end via a scheduled script.

**Stack:** Python (pandas, requests, openpyxl) · Power BI · Excel

## Why FX reporting

Currency exposure is a concrete, recognisable business reporting problem: a company
billing or paying in foreign currencies wants to know, every reporting period, how
exchange rates have moved, how volatile they've been, and whether the cost of hedging
that exposure is justified by the risk. That's the scenario this pipeline models.

## What it does

1. **Extract** (`pipeline/extract.py`) — pulls 90 days of daily FX rates for USD vs.
   EUR, GBP, JPY, INR, AUD from the [Frankfurter API](https://frankfurter.dev/)
   (free, no key, ECB reference rates).
2. **Transform** (`pipeline/transform.py`) —
   - Day-over-day % change and 7-day rolling volatility per currency (KPIs).
   - A parametric **Value-at-Risk** estimate per currency: the modelled worst-case
     adverse move on a fixed notional exposure at ~95% confidence, from observed
     rate volatility (**risk modelling**).
   - A **cost-benefit** comparison of a fixed hedging cost (basis points of
     exposure) against the modelled VaR, to flag whether hedging looks worthwhile
     for each currency (**cost-benefit analysis**).
3. **Load** (`pipeline/load.py`) —
   - Writes tidy CSVs (`data/fx_rates_history.csv`, `data/fx_kpi_summary.csv`)
     ready for Power BI or any BI tool to connect to directly.
   - Writes a formatted multi-sheet Excel workbook (`data/business_reporting_dashboard.xlsx`)
     with a styled KPI summary, raw history, and a rate-trend line chart.
4. **Schedule** — `run_report.py` is the single entrypoint and is idempotent
   (safe to re-run/schedule repeatedly). See `scheduling/README.md` for
   cron / launchd / Task Scheduler setup to automate the monthly refresh.

## Running it

```bash
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
./.venv/bin/python run_report.py
```

Outputs land in `data/`:

- `fx_rates_history.csv` — tidy long-format rate history (Power BI source)
- `fx_kpi_summary.csv` — per-currency KPI/risk/cost-benefit summary (Power BI source)
- `business_reporting_dashboard.xlsx` — formatted Excel report with a trend chart
- `pipeline_run_log.csv` — append-only run log (status, timestamp, row counts)

## Connecting Power BI

1. Open Power BI Desktop → **Get Data → Text/CSV**.
2. Load `data/fx_rates_history.csv` and `data/fx_kpi_summary.csv`.
3. Suggested visuals:
   - Line chart of `rate` over `date`, split by `currency`, from the history table.
   - Bar chart of `value_at_risk_95` vs `hedge_cost` per `currency`, from the KPI
     summary, to visualise the hedge recommendation.
   - Card visuals for headline KPIs (latest rate, period % change) per currency.
   - A slicer on `currency` to filter the whole report page.
4. Set the CSVs as a **scheduled refresh** data source (or point Power BI at the
   same CSVs the scheduled Python job regenerates monthly) to keep the dashboard
   current without manual reloading.
5. Save as `.pbix` in `dashboard/`.

*(The `.pbix` itself isn't included in this repo — Power BI's file format is built
by Power BI Desktop's GUI, not scriptable from Python. Everything the dashboard
reads is generated and version-controlled here.)*

```
├── scheduling/
│   ├── README.md          # cron / launchd / Task Scheduler instructions
│   └── com.user.fxreport.plist

```
